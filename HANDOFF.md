# Handoff – Trikaya Aufbau Simulator

Read this first in a new session (plus README.md for structure).

## How we work
- User writes in German; answer in German. "push it" / "publishen" = commit + `git push` to GitHub (main) → GitHub Actions builds and uploads via SFTP (repository secrets). Fallback from the PC: `npm run deploy:ftp` (SFTP to the user's united-domains webspace, folder `/main/trikaya-aufbau-simulator`, credentials in local `.env` – never read or print the password). Netlify (`npm run deploy`) only on explicit request – credits nearly used up. Public URL of the webspace folder: still unknown, ask the user.
- Dev server port can differ (autoPort, another chat may use 5173): use the port preview_start reports.
- Before every upload: full automated test in the browser preview (`?dev`):
  `const T=(await import('/dev/harness.js')).install(game); game.newGame(); T.runJobs(0,30)` – poll `T.log` in short calls (tool timeout 45 s); all jobs must say `done=true`, no `FAIL`.
- New tracks in `music/`: `scripts/music.mjs` runs automatically before dev/build (converts to `public/music`, writes `src/data/tracks.json`, regenerates credits). Always credit artists; **Calmy Jane is never credited** (her logo is on loading screen + menu instead). `music/credits.json`: per artist `name`, `link` (profile URL, one link per artist in the credits), `hidden`; per file `tracks` overrides (`artists`, `title`, `ignore`). Artists are split on &/x/vs/feat/comma and also picked up from titles ("(X Remix)", "feat. X"); identical duplicate files without "Artist - " are skipped. Known links: Astralica, StillBendana, LuneCell, Mekkanikka, Omikron, Dark Jochen; Geist still unknown (search link).
- Writing patches: use small Python scripts in the scratchpad (via Write tool) – heredocs mangle `\` and `'`. Escape `'` in JS strings as `\'`.

## Git / CI
Local git repo (branch `main`). Not in git: `.env`, source audio in `music/` (only converted `public/music/*.mp3` + `src/data/tracks.json` are committed – `scripts/music.mjs` skips itself when there's no source audio), promo videos. `.github/workflows/deploy.yml` builds and uploads via SFTP on every push to `main`, reading FTP_* from repository secrets (`scripts/deploy-ftp.mjs` prefers environment variables over `.env`). New music must be added on the PC (convert + commit the MP3s).

## Game in one paragraph
three.js + Vite. Third-person build-up game of the Trikaya festival (München-Allach). Crew camp with walk-in site cabins (office/Jan, Matze's, Corni's/Mahdi, Werkstatt/Zdenko radio, storage: Künstlergasse, Hühnercontainer), Aufenthaltszelt. Festival site: mainstage (dragon, posts drilled in quest), Forest Dome (Fabbe builds), Narnia Floor (Mia's crew, stages; elephant DJ booth, straw floor, stretch tent, royal tent), Firespace (south of Narnia; Shiva; fire island crew Aphi/Mux/Dennis/Sarah with flow toys), Hängemattenwald (Wiesel builds), Techno Floor (where "Biergarten" was; under a dark purple stretch tent; Verena's bar), entrance stretch tent, shops, straw bale sound walls. Finale once EVERY job is done (`Game.checkFinale`, errands don't count; toast when ≤3 left): guests → all stages play → cloudburst → crew moans in the office → end screen.

## Day rhythm (src/quests/Days.js)
4 build days + festival day. Every quest has `day: N` (and `night: true` for night jobs); `DaySystem.allows()` gates `available()`. All day jobs of the current day done → evening (night falls, night jobs open) → all night jobs done → sleep → next morning (Leo voice message via Jan). Day 1 ends with the timed lights job. Day 4's night job is the mapping → finale. State: `quests.state.day/phase` (old saves migrated). Dev: `game.devFast` (harness) makes transitions instant and skill games auto-win.
New step types: `park` (wheel loader precision parking through a cone lane, `src/quests/Parking.js`), `karma` (collect ✺ {need}, then talk to the giver – spends it). Work AND deliver steps can have `minigame` (`src/ui/Minigame.js`): `timing`, `mash`, `sequence` (memorise arrows), `balance` (hold to keep a marker in the zone), `order` (tap steps in the right order, opts.items), `match` (pair things, opts.pairs), `spot` (find the odd tile) – or an array of them in a row; work minigames run on EVERY target. NPC lines can carry `until`/`after` (quest id), `minDay`/`maxDay`, `night` (`NPC.fits`); generic progress lines skip the job's giver/crew. Step type `ride` (npc, at, radius, hopOn, dialog): pick someone up with the quad and drive them somewhere (q3 Juli, e1 Jan, g1 Schwarzhuber). Talk steps can have `cameo: 'leo'` (he runs in before the dialog). Horn: H / 📯 touch button in quad or loader, clears people aside, −1 karma. Phones get a compact one-line-per-task tracker (`UI.trackerCompact`). New jobs: x1_nuss (night 1, the special nut was in the workshop all along), r1_wassertank (park), g1_genehmigung (karma, Schwarzhuber). Search areas are larger; timed jobs that fail go back to their giver.
